# SanWich 更新紀錄

本頁整理使用者可見的功能與修正。V2 歷史依當時已發佈的版本整理，日期使用台灣時間；當時的功能、授權與更新方式不代表 V3 公測政策。

## V3 公測（尚未正式發行）

目前版本：`3.0.0-beta.5`。

### 3.0.0-beta.5 亮點

- 字級對齊更貼字：字幕斷句依每個字實際開口的時間切分；Shift+Enter 在游標處拆句，切點貼著下一個字。
- 支援 RTX 20／30／40 系列顯示卡；RTX 50 系列已在一台 5070 上驗證，其他型號仍在收集回報。
- 換機更簡單：PLUS 綁在別台電腦時，登入會詢問是否改綁到這台，一鍵完成。
- 字幕存放更乾淨：預設存在影片旁邊，同名自動加 (2)，不會覆蓋舊檔；執行紀錄收在軟體資料夾，30 天自動清除。
- 轉寫等待時提供 16 課快捷鍵教學。
- 字幕塊可用 Ctrl+C／V 複製貼上；貼上位置會壓到其他字幕時會提醒。
- 操作更流暢：開啟更快，字幕表格操作、拖曳、播放換頁與自動存檔不再卡頓。
- AI 校對更穩：「的／地／得」不再被誤擋、「牠」不再被誤改成「它」，連線逾時自動重試。
- 程式本體 `SanWich_v3.0.0-beta.5_App_Lightweight.zip` 約 437 MB；AI 引擎約 3.1 GB，於首次開啟時自動下載。舊版（beta.4）使用者請重新下載並解壓縮到新資料夾，首次開啟會重新下載引擎。
- 公測規則：程式可自由下載；填表即開通會員（全功能），須以填表的 Email 登入，可使用至 2026/10/31，之後回到 Free；每日名額有限，額滿後隔天早上 10:00 再開放。問題回報請寄 service@wikivibe.studio（附畫面截圖與操作步驟）。

### 先前開發摘要

以下為截至 2026-10-08 的開發摘要；項目已有實作或範圍測試紀錄，公測實際開放的功能仍以候選安裝包的驗收結果與發行說明為準。

### 安裝與首次使用

- 主程式與 AI 運算環境分開下載：主程式為 `SanWich_v<版本>_App_Lightweight.zip`，運算環境 `SanWich_AI_Engine_CUDA12_v3.zip` 存放於 Hugging Face，更新主程式時不必重新下載運算環境。
- 首次開啟提供教學，並檢查運算環境與所選模型；可在教學期間下載所需檔案，下載完成並通過檢查後才顯示就緒，取消後可重試。
- 可在準備畫面以「載入模型包」安裝事先下載的運算環境，安裝前會校驗檔案完整性。
- 純本機語音辨識（單一來源 5 分鐘內）不需登入；使用 AI 校對時需以電子郵件登入。
- 一般設定加入亮色／暗色主題、轉寫前詢問設定、重看導覽與快捷鍵列表。

### 字幕閱讀與校對

- 加入訪談／長片、綜藝／短影音與自訂斷句風格。
- 改善中英文、數字混合字幕的長度判斷，減少完整詞語被拆開的情況。
- 修正部分數字列舉及英文詞組在字幕處理後失去必要空格的問題。
- 改善人名、組織名稱與補充資料的校對處理；仍需要人工確認的內容會保留提示。
- 完成詳情可分別查看已套用的修改與保留原稿的紀錄，長句可展開，文字可複製；部分校對未完成時仍會顯示狀態。

### 編輯器與輸出

- 語者欄位、篩選、批次更名及依語者匯出（語者分離／Speaker Diarization）：暫時取消，目前為開發中，不在本次公測範圍。
- 加入字幕樣式庫、數值拉桿、快速重設，以及外部／置中／內部描邊選項。
- 加入圖片圖層，可在預覽中移動、等比例縮放與復原，並隨專案保存（PLUS／PRO）。
- 改善燒錄影片與預覽之間的字幕大小、底框顏色及邊緣清晰度差異。
- 修正部分 MKV 影片匯入時觸發不必要處理或卡住的問題，改善開始轉寫的等待情況。
- 加入儲存空間管理、資料位置搬移及快取清理；字幕匯出可記住上次成功使用的資料夾。

### 公測前仍在確認的項目

- 乾淨 Windows 電腦上的首次安裝、啟動及完整轉寫。
- 真實影片的字幕品質、播放同步，以及 DaVinci Resolve／EDIUS 匯入。
- 圖片圖層、資料搬移與長片輸出的實機操作。
- 登入、授權、使用限制、更新成功與更新失敗復原。
- 各功能的公測開放範圍；雙語翻譯、YouTube 匯入與範圍聽寫尚未列為公測承諾。

## V2 已發佈版本

### v2.7.5｜2026-09-09

- 改善過長字幕的拆分，減少少數長句影響整份字幕分段的情況。
- 調整相鄰字幕的結束時間，減少過短空隙；文字不會因此合併。
- 改善連續重複字幕的清理；實際重複發言仍需對照原音確認。

## 歷史功能的使用限制

- 語音辨識、校對、重複字幕清理及時間碼仍需人工對照原音確認。
- 首次使用部分功能需要網路下載及額外磁碟空間，需求依版本而異。
- 歷史版本的使用限制、授權與更新方式各自適用；不能直接視為 V3 公測規則。
