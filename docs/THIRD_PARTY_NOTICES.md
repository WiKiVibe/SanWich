# 第三方元件聲明

SanWich 使用下列第三方元件。各元件依其各自的授權條款提供；每個發行版本實際隨附的元件版本、完整授權文字與必要通知，以該下載版本內附的授權文件為準。

| 元件 | 用途 | 授權 | 官方資訊 |
|---|---|---|---|
| Qt for Python（PySide6、Shiboken6），含 Qt Core、Gui、Widgets、Multimedia | 應用程式介面與影音播放 | LGPLv3 | [Qt for Python](https://doc.qt.io/qtforpython-6/)、[Qt 授權說明](https://doc.qt.io/qt-6/licensing.html) |
| Qt Multimedia 所含第三方元件（可能包含 FFmpeg 及其他寬鬆授權函式庫） | 影音播放 | 依各元件授權 | [Qt Multimedia](https://doc.qt.io/qt-6/qtmultimedia-index.html) |
| FFmpeg（LGPL 相容建置） | 音訊轉檔、預覽畫格擷取與字幕燒錄 | LGPL | [FFmpeg 授權說明](https://ffmpeg.org/legal.html) |
| yt-dlp | 線上影片音訊取得 | Unlicense | [yt-dlp LICENSE](https://github.com/yt-dlp/yt-dlp/blob/master/LICENSE) |
| TASA Explorer v2.012（TASA Typeface Collection Project Authors） | 介面字型 | SIL Open Font License 1.1 | [TASA Typeface Collection](https://github.com/localremotetw/TASA-Typeface-Collection) |
| 其他 Python 執行期相依套件 | 語音辨識與執行環境 | 依各套件授權 | 見下載版本隨附的授權文件 |

依 LGPL 條款，使用者可依適用條款替換相關的 LGPL 函式庫；對應原始碼或取得方式依各發行版本的說明提供。

**影音編碼與專利**：軟體授權不必然包含所有影音編碼格式（例如 H.264、H.265）的專利權利；相關權利依您的使用情境與所在地區而定。
